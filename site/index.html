Features

Everything a clicker needs. Nothing it doesn't.

Thoughtful defaults, a clean interface, and the power features you reach for once the basics aren't enough.



Precise speed

Up to 1000 clicks per second or an exact interval down to 1 ms. Drift-free timing with optional human-like jitter.



Click anywhere

At the cursor, a fixed point, a random spot inside an area, or along a route of points.



Click routes

Chain points with their own mouse button, single or double click and pause. In order or shuffled.



Pick on screen

A full-screen overlay with a pixel loupe and live coordinates. Exact on multi-monitor and mixed-DPI setups.



Keyboard, too

Press any key or combination with Ctrl, Shift or Alt instead of clicking. Sent as scan codes, which many games need.



Global hotkeys

Start and stop with F6 — toggle or hold-to-click — and add route points with F7, even while minimized.



Profiles

Keep a setup per game or task and switch in one click. Every change is saved automatically.



Built-in safety

Never clicks its own window, stops when you move the mouse away, and can wait before the first click.



Limits & live stats

Stop after N clicks, N route cycles or a time limit. Watch real clicks per second on a live graph.

How it works

Up and clicking in a minute.

Download & run

One exe, no installer and no runtime. Put it anywhere and start it.

Set it up

Pick the speed and the button, then choose where to click — or draw a route right on the screen.

Press F6

Clicking starts; press it again to stop. Works from any app, even with clkr minimized.

FAQ

Questions

Windows says the app is unrecognized. Is it safe?

The exe isn't code-signed, so SmartScreen asks once: click “More info → Run anyway”. The full source is on GitHub and every release is built from it by GitHub Actions.

My antivirus complains.

Some antivirus products flag auto clickers in general because they synthesize mouse and keyboard input. clkr does nothing else: no network access, no installer, no background services.

Does it work in games?

In most of them. Some games with anti-cheat block synthetic input or forbid automation — check the rules of the game you play.

Where are my settings?

In %APPDATA%\clkr\clkr.json. For a portable setup, put an empty clkr.json next to clkr.exe and clkr will keep its settings there.

What do I need to run it?

64-bit Windows 10 or 11 with OpenGL 2.0, which any graphics driver from the last decade provides. Virtual machines without graphics acceleration may not.
